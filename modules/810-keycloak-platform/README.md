This module is responsible for deployment of [Keycloak](https://www.keycloak.org/) in the cluster

Depends on modules:
- [cnpg-postgres-platform](/modules/241-cnpg-postgres-platform/README.md) which is needed postgres DB
- [qvantel-glue](/modules/320-qvantel-glue/README.md) which is needed for SQL installers support
- [vault-platform](/modules/140-vault-platform/README.md) which is used to manage DB credentials
